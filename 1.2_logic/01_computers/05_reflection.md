# Part 5 – Final Reflection
Write **200–300 words** describing your learning experience during this lab.
Consider:
* What surprised you about computer hardware?
* What components were new to you?
* What challenges did you face?
* What did you learn about embedded systems?


During this technology project, I learned about different computer components and their functions. One thing that surprised me was how all the hardware parts work together to make a computer run. I used to think that the processor was the main part and other compoents were less important, but now I understand that RAM, storage, the motherboard and cooling system are also needed. I also learned about the Raspberry Pi and its GPIO pins, which can be used to connect sensors and other electronic devices. The SoC was also interesting because it combines important computing functions into a single chip.

One challenge for me was undestanding the technical names and remembering what each component does. At first, it was confusing to understand the difference between RAM and storage. I learned that RAM holds data temporarily while programs are running, but storage keep files and softwares even when the computer is switched off. Identifying the components and understanding their specifications also needed more attention. I realised that I should check the information carefully instead of guessing.

This project helped me understand embedded systems in a more practical way. I learned that devices like the Raspberry Pi are small computers which can be used for specific projects, such as controlling sensors, building robots and creating smart home systems. Many component are placed on one board to save space, reduce cost and use less electricity. Overall, I gained a better understanding of computer hardware and how embedded systems are used in real life. I still need more practice, but this project helped me learn the basics and made me more interested in technology.
